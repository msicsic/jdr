# Captures et successeurs du lot 86

`auberge-1985-600.json.gz` continue la capture à 480 min avec le moteur
`02c8e8b` (`banc_pnj.executer(monde, 600)`), sans Luna ni sauvegarde utilisateur.

`gestes-attendus.json` est produit sur `02c8e8b` par
`tools/comparer_gestes_noeud.py --depot <témoin> --sortie <fichier>`.
Chaque empreinte couvre les états développés, tous leurs successeurs dans l'ordre,
leurs coûts flottants hexadécimaux, les arguments des suites différées et les
marques de découverte. Les captures mine/auberge à 480 min précèdent ce lot.
